# AI Lounge Projects

A community showcase for projects built by members of AI Developers Lounge. Share what you are building, discover other projects, and exchange thoughtful feedback.

## Projects

- [T-Zero](projects/T-Zero/) — an open-source context compression tool for AI coding assistants. This Git submodule points to [the original repository](https://github.com/toprakahmetaydogmus/TZeroAlgorithm); see its own README and MIT license.

Want to add yours? See [CONTRIBUTING.md](CONTRIBUTING.md).

To clone the showcase with its submodules, run:

```bash
git clone --recurse-submodules https://github.com/toprakahmetaydogmus/AI-Lounge-Projects.git
```

For an existing clone, run `git submodule update --init --recursive`.

## Community

Everyone is welcome to propose a project through a pull request. Submissions are reviewed by maintainers before merging; opening a PR does not automatically publish it. Please be respectful and give constructive feedback.
