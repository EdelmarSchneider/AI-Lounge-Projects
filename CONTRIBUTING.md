# Contributing

Thank you for sharing your work! You can add an open-source project or propose improvements to this showcase.

1. Fork this repository and create a branch.
2. Add one concise entry under **Projects** in `README.md`, using the format below. Link to your project's existing repository rather than copying someone else's code.
3. Open a pull request describing your project. Maintainers will review it and may ask questions before merging.

```markdown
- [Project name](https://github.com/owner/repository) — one sentence explaining what it does.
```

Please only submit projects you own or have permission to share. Provide accurate descriptions, respect each project's license, and do not include credentials or private information. Be kind and constructive in discussions. Spam and harmful content may be declined.

New to GitHub? You can edit `README.md` on GitHub, choose **Create a new branch**, and follow the prompts to propose a change.
